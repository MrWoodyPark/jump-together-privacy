앱 지원문의하기

같은 Wi-Fi에서 만나 함께 뛰는 놀이터.

개발자는 앱에서 회원가입 정보나 플레이 기록을 수집하는 서버를 운영하지 않습니다.

이름·캐릭터·최고 도달 단계는 기기에 저장됩니다. 함께 플레이할 때는 같은 방의 기기 사이에서 이름·캐릭터·게임 상태를 일시적으로 주고받습니다.

시행일: 2026년 10월 20일 · 최종 수정일: 2026년 10월 20일

1. 처리하는 정보와 목적

항목용도와 처리 장소
최대 5글자 이름, 선택한 캐릭터앱 프로필과 캐릭터 이름 표시. 기기 내 저장, Wi-Fi 방 참가 시 해당 방 참가자에게 표시.
최고 도달 단계개인 기록 표시. 기기 내 저장.
방 이름, 임시 참가자 ID, 접속 상태, 점프·이동 입력, 캐릭터 위치, 줄 상태, 단계·남은 횟수방 검색과 동기화. 앱 실행 중 메모리에서 처리하며 방을 만든 기기와 참가 기기 사이에서 전송.

실명 대신 별명을 사용할 수 있습니다. 방 이름은 같은 로컬 네트워크에서 앱으로 방을 찾는 사람에게 보일 수 있고, 참가자의 이름과 캐릭터는 같은 방 사람들에게 보입니다. 앱은 정확한 위치, Wi-Fi 이름(SSID), 연락처, 사진, 마이크, 카메라, 광고 식별자를 요청하지 않습니다.

2. 권한과 기기 간 연결

로컬 네트워크 권한은 같은 Wi-Fi의 방을 찾고 함께 플레이하는 데 사용합니다. 방을 만든 기기가 게임 진행을 동기화하며 별도의 개발자 서버나 인터넷 매칭 서비스에 게임 데이터를 보내지 않습니다. 권한을 허용하지 않아도 혼자 플레이할 수 있습니다. iOS 설정에서 앱의 로컬 네트워크 권한을 변경할 수 있습니다.

앱은 로컬 TCP 연결을 사용하며 앱 자체의 TLS 암호화나 방 비밀번호를 제공하지 않습니다. 신뢰할 수 있는 네트워크에서 사용하고 별명에 민감한 정보를 입력하지 마세요.

3. 보관과 삭제

프로필과 최고 도달 단계는 기기에 저장되며, 프로필은 앱에서 이름·캐릭터를 바꾸어 수정할 수 있습니다. 앱을 삭제하면 앱의 기기 내 저장 정보도 삭제됩니다. 운영체제의 백업·복원은 Apple 설정에 따릅니다. 라운드의 임시 게임 상태는 개발자의 영구 저장소에 기록하지 않으며 방 종료·앱 종료 시 해당 세션 처리가 끝납니다.

4. 외부 제공·광고·분석

개발자는 광고·분석·계정·클라우드 SDK를 사용하지 않으며 앱 데이터를 광고, 판매 또는 사용자 추적에 이용하지 않습니다. 함께하기를 선택하면 방 동기화에 필요한 데이터가 같은 방의 다른 사용자 기기에 전송됩니다. 개발자가 별도로 보관하거나 제3자 업체에 제공하는 앱 기록은 없습니다.

5. 문의 이메일과 정책 웹사이트

문의 이메일을 보내면 답변을 위해 발신 주소와 문의 내용을 메일 서비스에서 처리할 수 있습니다. 문의를 해결하는 데 필요한 범위에서만 이용하며 불필요해진 문의 정보는 삭제를 요청할 수 있습니다.

이 웹사이트는 GitHub Pages로 제공됩니다. 웹 접속 시 GitHub가 보안과 서비스 제공을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. 이는 앱의 로컬 게임 데이터와 별개입니다. 이 정책 페이지 자체에는 광고·분석 도구와 별도 추적 쿠키를 넣지 않았습니다. GitHub 개인정보처리방침을 참고하세요.
